# **Маълумот**
Меню барои идоракунии муҳити Bitrix, ки барои **Debian 12 / Debian 13** мутобиқ карда шудааст. Ҳадафи асосӣ — Debian 13 (trixie): лоиҳа муҳити CentOS 9-ро дар мошинҳои муосири Debian иваз мекунад.  
Муҳит дар асоси **ҳуҷҷатгузории расмии 1С-Битрикс** ҷамъ оварда шудааст — курси [«Танзими муҳит барои Debian 13»](https://dev.1c-bitrix.ru/learning/course/index.php?COURSE_ID=32) (бастаҳо, Nginx, PHP, Apache, MySQL/MariaDB, PostgreSQL, Redis, push-server) — ва талаботи расмии система барои маҳсулоти Bitrix. Автоматикунонӣ аз рӯи **схемаи стандартии Ansible** сохта шудааст (`playbooks/` + `roles/` бо `defaults`, `vars`, `tasks`, `meta`), танҳо модулҳои `ansible.builtin` истифода мешаванд, бе коллексияҳои беруна.

---

# **Имкониятҳои муҳит**
- Насби пурраи автоматии ҳамаи ҷузъҳои зарурӣ:  
  **Ansible, PHP 8.3 (пешфарз), MySQL 8.4 LTS, Nginx, Apache, Redis, Push & Pull сервер.**
- **Интихоби муҳаррики пойгоҳи додаҳо: Oracle MySQL 8.4 LTS ё Percona Server 8.4 LTS** (тағйирёбандаи `DB_ENGINE`).
- **Дастгирии композит**.
- Тақсими статикӣ **бо Brotli**.
- Имконияти **истифодаи конфигуратсияҳои шахсии Nginx** бе тағйири стандартӣ.
- Дастгирии **ҷустуҷӯи пурраи матнӣ бо Sphinx**.
- Имконияти **насб ва танзими сервери табдили ҳуҷҷатҳо (`LibreOffice`, `ImageMagick`)**.
- Имконияти **насб ва мониторинги Netdata**.

# **Имкониятҳои меню**
- Дидани рӯйхати сайтҳо.
- Эҷод ва нест кардани сайтҳо дар **ҳолати аслӣ ва пайванди рамзӣ**.
- Ҳангоми эҷоди сайт дар ҳолати аслӣ **агентҳоро ба CRON** автоматӣ интиқол медиҳад.
- Барориши **шаҳодатномаҳои SSL Let’s Encrypt**.
- Идоракунии **интиқоли HTTP → HTTPS**.
- **Иваз кардани версияҳои PHP**.
- **Танзими SMTP** (умумӣ ва барои ҳар як сайт алоҳида).
- **Навсозӣ, бозоғозӣ ва хомӯш кардани сервер** тавассути меню.
- Огоҳӣ дар бораи баромадани версияи нави меню.
- **Навсозии меню бо як фармон**:
  ```bash
  update_menu
  ```
- **Ду забони интерфейс — русӣ ва англисӣ** — аз рӯи локали система ба таври худкор интихоб мешаванд (`ru_*` → русӣ, дигар → англисӣ); бо тағйирёбандаи `BS_MENU_LANG` маҷбурӣ таъин кардан мумкин аст.
- **PostgreSQL барои Bitrix** — насб ва нест кардан аз менюи иловаҳо, бо пресетҳои `postgresql.conf` аз рӯи ҳаҷми RAM.

## Интихоби муҳаррики пойгоҳи додаҳо: MySQL ё Percona Server
Насбкунанда имкон медиҳад **Oracle MySQL 8.4 LTS** ё **Percona Server for MySQL 8.4 LTS**-ро интихоб кунед. Ҳарду ҳамон хидмат (`mysql.service`), ҳамон ҷузвдони конфигуратсия (`/etc/mysql/conf.d/99-bitrix.cnf`) ва ҳамон режими аутентификатсия (`mysql_native_password`)-ро истифода мебаранд, бинобар ин Bitrix дар ҳар ду ҳолат якхела кор мекунад.

```bash
# Интихоби интерактивӣ (пешфарз — MySQL)
bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)

# Percona Server 8.4 LTS, бе савол
DB_ENGINE=percona bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)

# Oracle MySQL 8.4 LTS, бе савол
DB_ENGINE=mysql bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)
```

**Дар Debian 13 (trixie)-и тоза, amd64 санҷида шуд:** PHP 8.3.36 (танҳо шохаи PHP дар система), MySQL/Percona 8.4.11, Nginx 1.26.3, Apache 2.4.69, Node.js 20.19.2, push-server 0.4.0; ҳамаи хидматҳо фаъоланд; сохтани сайт дар режимҳои `full` ва `link` кор мекунад.

## PostgreSQL барои портали Bitrix

Аз меню насб мешавад: банди `8` → «Компонентҳои иловагӣ» → `4`. MySQL корро идома медиҳад — пойгоҳи додаҳо ҳангоми насби портал интихоб мешавад.

| RAM, ГБ | Ҳавзи буфер | Кеши банақшагир | work_mem | Хизматрасонӣ |
|---|---|---|---|---|
| <3 | 512MB | 1536MB | 4MB | 128MB |
| 3&#8209;6 | 1GB | 3GB | 6MB | 256MB |
| 6&#8209;12 | 2GB | 6GB | 8MB | 512MB |
| 12&#8209;24 | 4GB | 12GB | 12MB | 1GB |
| 24&#8209;48 | 8GB | 24GB | 16MB | 1GB |
| ≥48 | 16GB | 48GB | 24MB | 2GB |

| RAM, ГБ | Пайвастҳо | Буфери WAL | Буфери temp |
|---|---|---|---|
| <3 | 40 | 16MB | 8MB |
| 3&#8209;6 | 60 | 16MB | 8MB |
| 6&#8209;12 | 80 | 16MB | 16MB |
| 12&#8209;24 | 85 | 16MB | 24MB |
| 24&#8209;48 | 200 | 16MB | 32MB |
| ≥48 | 300 | 16MB | 48MB |

Номҳои пурраи параметрҳо: ҳавзи буфер — `shared_buffers`, кеши банақшагир — `effective_cache_size`, хизматрасонӣ — `maintenance_work_mem`, пайвастҳо — `max_connections`, буфери WAL — `wal_buffers`, буфери temp — `temp_buffers`.

Ба таври худкор сохта мешавад: пойгоҳи `bitrix` (`LC_CTYPE='C.UTF-8' TEMPLATE template0`), корбари `bitrix`, `GRANT CREATE` ба схемаи `public`, васеъшавии `pgcrypto`, аутентификатсияи паролӣ дар `pg_hba.conf`.

Пресет аз рӯи аввалин ҳадди мувофиқ интихоб мешавад; маҷбурӣ — `BS_POSTGRES_PRESET` дар `config.sh`.

## Вобастагиҳои дохилшуда (`vendor/`)

Ҳама чизе, ки қаблан аз сайтҳои бегона боргирӣ мешуд, дар репозиторий — `vendor/`: модулҳои
nginx gzip/zstd (дар Debian нестанд), сервери push&pull, конфигуратсияҳои Bitrix барои
PHP/Nginx/Apache, скриптҳои насби Bitrix, скрипти насби Netdata ва калидҳои репозиториҳо.
Насбкунанда ҷузвдони `vendor`-ро ба `/root/vm_menu/vendor` нусхабардорӣ мекунад, `vendor/CHECKSUMS.sha256`-ро
месанҷад ва файлҳоро аз ҳамон ҷо мегирад; шабака танҳо дар сурати набудани нусхаи маҳаллӣ
истифода мешавад. Навсозӣ — `tools/vendor-fetch.sh`, санҷиш — `tools/vendor-fetch.sh --check`.
Репозиториҳои Debian, deb.sury.org, MySQL/Percona ва Netdata қасдан берунӣ мемонанд: онҳо
сарчашмаи бастаҳо ва навсозиҳои амниятанд, нусхаҳои дохилшуда фавран кӯҳна мешаванд.

### Скрипти restore.php — танҳо бо дархост

`restore.php` архиви нусхаи эҳтиётиро дар сервер мекушояд, бинобар ин нигоҳ доштани он дар
каталоги сайт ба таври доимӣ хатарнок аст. Баръакси `bitrixsetup.php` он дар `vendor/`
**нигоҳ дошта намешавад**, ҳангоми сохтани сайт **нусхабардорӣ намешавад** ва танҳо аз меню
бо дархост (`8` → `5` → `1`) аз суроғаи расмӣ
`https://www.1c-bitrix.ru/download/files/scripts/restore.php` ҷойгир карда мешавад
(соҳиб — корбари сайт, ҳуқуқҳо `0640`). Баъди барқарор кардани портал скрипт бояд нест карда
шавад (`8` → `5` → `2`). Инро нақши `manage_restore_script` (`PLACE` / `REMOVE`) ва
плейбуки `manage_restore_script.yaml` иҷро мекунад.

Сарчашмаҳои расмӣ: сервери push&pull — `https://repo.bitrix24.tech/vm/push-server-0.4.0.tgz`,
конфигуратсияҳои PHP/Nginx/Apache — `https://dev.1c-bitrix.ru/docs/chm_files/debian.zip`,
насбкунанда — `https://www.1c-bitrix.ru/download/scripts/bitrixsetup.php`.

### Назорати якгӯшт (SHA256)

Ҳар скрипт, конфиг ва баста халтаи назоратӣ дорад. Манускриптҳо дар репозиторий ҷойгиранд:
`CHECKSUMS.sha256` (реша: насбкунанда, навсозкунанда, `tools/`, `repositories/`),
`vm_menu/CHECKSUMS.sha256` (тамоми меню: `menu.sh`, `bash_scripts/`, плейбукҳо ва рольҳои
`ansible/`, қолабҳо ва конфигуратсияҳо) ва `vendor/CHECKSUMS.sha256` (бастаҳо ва файлҳои
дохилшуда).

Санҷишҳо худкор иҷро мешаванд: ҳангоми насб (`sha256sum -c` аз рӯи ҳамаи манускриптҳо,
номувофиқӣ насбро қатъ мекунад), ҳангоми навсозии меню (менюи боргиришуда пеш аз иваз кардани
нусхаи корӣ санҷида мешавад), пеш аз насби бастаҳои дохилшудаи nginx `.deb` ва дар `vendor_get`
пеш аз истифодаи ҳар файли дохилшуда. Аз нав ҳисоб кардани манускриптҳо —
`tools/checksums.sh --update`, санҷиш — `tools/checksums.sh --check`.

# **Истифода**
Меню дар **`/root/vm_menu`** насб карда мешавад ва барои осонӣ **пайванди рамзӣ** эҷод мегардад:
- `/root/menu.sh` → `/root/vm_menu/menu.sh`

Менюро бо фармонҳои зерин оғоз кардан мумкин аст:
```bash
./menu.sh   # Агар дар /root бошед
/root/menu.sh   # Аз дигар директорияҳо оғоз кардан
```
Инчунин, роҳ ба меню **ба таври худкор ба `.profile` ворид карда мешавад**, бинобар ин **он ҳангоми пайвастшавӣ бо SSH фавран оғоз мешавад**.

# **Танзимот**
Меню фасеҳ аст ва танзимшаванда мебошад.  
Ҳамаи параметрҳоро дар файли зерин тағйир додан мумкин аст:
```bash
/root/vm_menu/bash_scripts/config.sh
```
Бо нобаёнӣ ҳама чиз танзим шудааст, аммо дар ҳолати зарурӣ муҳитро мувофиқи эҳтиёҷоти худ танзим кардан мумкин аст.

### Забони интерфейс

Меню дузабона аст: русӣ ва англисӣ. Забон аз рӯи локали система ба таври худкор интихоб мешавад:
`ru_RU.UTF-8` (ё ҳар як `ru_*`) — русӣ; ҳар як дигар, аз ҷумла `tg_TJ.UTF-8` ва `C.UTF-8` — англисӣ.

Интихоби маҷбурӣ — тағйирёбандаи муҳит ё параметри `BS_MENU_LANG` дар `config.sh`:

```bash
BS_MENU_LANG=en /root/menu.sh   # забони англисӣ дар сервери дорои локали русӣ
BS_MENU_LANG=ru /root/menu.sh   # забони русӣ дар сервери дорои локали англисӣ
```

Ҳамаи сатрҳои интерфейс дар як файл нигоҳ дошта мешаванд — `/root/vm_menu/bash_scripts/i18n.sh`
(луғатҳои `MSG_RU` ва `MSG_EN`).

# **Ақпарат**
Bitrix ортасын басқаруға арналған мәзір, **Debian 12 / Debian 13** үшін бейімделген. Негізгі мақсат — Debian 13 (trixie): жоба заманауи Debian машиналарында CentOS 9 ортасын алмастырады.  
Орта **1С-Битрикс ресми құжаттамасы** бойынша жиналған — [«Debian 13 үшін ортаны баптау»](https://dev.1c-bitrix.ru/learning/course/index.php?COURSE_ID=32) курсы (пакеттер, Nginx, PHP, Apache, MySQL/MariaDB, PostgreSQL, Redis, push-server) — және Bitrix өнімдерінің ресми жүйелік талаптарына сай. Автоматтандыру **Ansible-дың стандартты схемасы** бойынша құрылған (`playbooks/` + `roles/`: `defaults`, `vars`, `tasks`, `meta`), тек `ansible.builtin` модульдері қолданылады, сыртқы коллекцияларсыз.

# **Ортаның мүмкіндіктері**
- Барлық қажетті компоненттердің толық автоматты түрде орнатылуы:  
  **Ansible, PHP 8.3 (әдепкі), MySQL 8.4 LTS, Nginx, Apache, Redis, Push & Pull сервері.**
- **ДҚ қозғалтқышын таңдау: Oracle MySQL 8.4 LTS немесе Percona Server 8.4 LTS** (`DB_ENGINE` айнымалысы).
- **Композитті қолдау**.
- Статикалық файлдарды **Brotli арқылы беру**.
- Стандартты конфигурацияларды өзгертпей **жеке Nginx конфигурацияларын пайдалану** мүмкіндігі.
- **Sphinx арқылы толық мәтіндік іздеуді** қолдау.
- **Құжаттарды түрлендіру серверін (`LibreOffice`, `ImageMagick`) орнату және баптау** мүмкіндігі.
- **Netdata орнату және мониторинг жасау** мүмкіндігі.

# **Мәзір мүмкіндіктері**
- Веб-сайттар тізімін қарау.
- Веб-сайттарды **ядро және символдық сілтеме режимінде** жасау және жою.
- Ядро режимінде сайт жасағанда агенттерді **CRON-ға** автоматты түрде көшіру.
- **Let’s Encrypt SSL сертификаттарын** шығару.
- **HTTP → HTTPS бағыттауларын басқару**.
- **PHP нұсқаларын өзгерту**.
- **SMTP параметрлерін өзгерту** (жалпы немесе әр сайт үшін жеке).
- **Серверді жаңарту, қайта қосу және өшіру**.
- Жаңа мәзір нұсқасы шыққаны туралы хабарлау.
- **Бір пәрменмен мәзірді жаңарту**:
  ```bash
  update_menu
  ```
- **Интерфейстің екі тілі — орыс және ағылшын** — жүйе локаліне қарай автоматты түрде таңдалады (`ru_*` → орыс тілі, кез келген басқа → ағылшын тілі); `BS_MENU_LANG` айнымалысымен мәжбүрлеп орнатуға болады.
- **Bitrix үшін PostgreSQL** — қосымшалар мәзірінен орнату және жою, `postgresql.conf` пресеттері RAM көлемі бойынша таңдалады.

## Дерекқор қозғалтқышын таңдау: MySQL немесе Percona Server
Орнатушы **Oracle MySQL 8.4 LTS** немесе **Percona Server for MySQL 8.4 LTS** таңдауға мүмкіндік береді. Екеуі де бір қызметті (`mysql.service`), бір конфигурация каталогын (`/etc/mysql/conf.d/99-bitrix.cnf`) және бір аутентификация режимін (`mysql_native_password`) пайдаланады, сондықтан Bitrix екі жағдайда да бірдей жұмыс істейді.

```bash
# Интерактивті таңдау (әдепкі — MySQL)
bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)

# Percona Server 8.4 LTS, сұрақсыз
DB_ENGINE=percona bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)

# Oracle MySQL 8.4 LTS, сұрақсыз
DB_ENGINE=mysql bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)
```

**Таза Debian 13 (trixie), amd64 жүйесінде тексерілді:** PHP 8.3.36 (жүйедегі жалғыз PHP тармағы), MySQL/Percona 8.4.11, Nginx 1.26.3, Apache 2.4.69, Node.js 20.19.2, push-server 0.4.0; барлық қызметтер белсенді; сайтты `full` және `link` режимдерінде құру жұмыс істейді.

## Bitrix порталы үшін PostgreSQL

Мәзірден орнатылады: `8` → «Қосымша компоненттер» → `4`. MySQL жұмысын жалғастырады — ДҚЖ порталды орнату кезінде таңдалады.

| RAM, ГБ | Буферлік пул | Жоспарлаушы кэші | work_mem | Қызмет көрсету |
|---|---|---|---|---|
| <3 | 512MB | 1536MB | 4MB | 128MB |
| 3&#8209;6 | 1GB | 3GB | 6MB | 256MB |
| 6&#8209;12 | 2GB | 6GB | 8MB | 512MB |
| 12&#8209;24 | 4GB | 12GB | 12MB | 1GB |
| 24&#8209;48 | 8GB | 24GB | 16MB | 1GB |
| ≥48 | 16GB | 48GB | 24MB | 2GB |

| RAM, ГБ | Қосылымдар | WAL буфері | Temp буфері |
|---|---|---|---|
| <3 | 40 | 16MB | 8MB |
| 3&#8209;6 | 60 | 16MB | 8MB |
| 6&#8209;12 | 80 | 16MB | 16MB |
| 12&#8209;24 | 85 | 16MB | 24MB |
| 24&#8209;48 | 200 | 16MB | 32MB |
| ≥48 | 300 | 16MB | 48MB |

Параметрлердің толық атаулары: буферлік пул — `shared_buffers`, жоспарлаушы кэші — `effective_cache_size`, қызмет көрсету — `maintenance_work_mem`, қосылымдар — `max_connections`, WAL буфері — `wal_buffers`, temp буфері — `temp_buffers`.

Автоматты түрде жасалады: `bitrix` базасы (`LC_CTYPE='C.UTF-8' TEMPLATE template0`), `bitrix` пайдаланушысы, `public` схемасына `GRANT CREATE`, `pgcrypto` кеңейтімі, `pg_hba.conf` ішінде құпиясөз аутентификациясы.

Пресет бірінші сәйкес шек бойынша таңдалады; мәжбүрлеп — `config.sh` ішіндегі `BS_POSTGRES_PRESET`.

## Кірістірілген тәуелділіктер (`vendor/`)

Бұрын бөгде сайттардан жүктелетін барлық нәрсе репозиторийде — `vendor/`: nginx gzip/zstd
модульдері (Debian-да жоқ), push&pull сервері, Bitrix-тің PHP/Nginx/Apache конфигурациялары,
Bitrix орнату скрипттері, Netdata орнату скрипті және репозиторий кілттері. Орнатушы `vendor`
каталогын `/root/vm_menu/vendor` ішіне көшіреді, `vendor/CHECKSUMS.sha256` тексереді және файлдарды
сол жерден алады; желі тек жергілікті көшірме болмағанда қолданылады. Жаңарту —
`tools/vendor-fetch.sh`, тексеру — `tools/vendor-fetch.sh --check`. Debian, deb.sury.org,
MySQL/Percona және Netdata репозиторийлері әдейі сыртқы күйінде қалады: олар пакеттер мен
қауіпсіздік жаңартуларының көзі, кірістірілген көшірмелер бірден ескіреді.

### restore.php скрипті — тек сұраныс бойынша

`restore.php` серверде резервтік көшірме архивін ашады, сондықтан оны сайт каталогында тұрақты
ұстау қауіпті. `bitrixsetup.php`-тен өзгеше, ол `vendor/` ішінде **сақталмайды**, сайт
құрылғанда **көшірілмейді** және тек мәзірден сұраныс бойынша (`8` → `5` → `1`) ресми
мекенжайдан `https://www.1c-bitrix.ru/download/files/scripts/restore.php` орналастырылады
(иесі — сайт пайдаланушысы, құқықтары `0640`). Портал қалпына келтірілгеннен кейін скрипт
жойылуы керек (`8` → `5` → `2`). Мұны `manage_restore_script` рөлі (`PLACE` / `REMOVE`) және
`manage_restore_script.yaml` плейбукі орындайды.

Ресми көздер: push&pull сервері — `https://repo.bitrix24.tech/vm/push-server-0.4.0.tgz`,
PHP/Nginx/Apache конфигурациялары — `https://dev.1c-bitrix.ru/docs/chm_files/debian.zip`,
орнатушы — `https://www.1c-bitrix.ru/download/scripts/bitrixsetup.php`.

### Тұтастықты бақылау (SHA256)

Әрбір скрипт, конфиг және пакеттің бақылау сомасы бар. Манифесттер репозиторийде:
`CHECKSUMS.sha256` (түбір: орнатушы, жаңартушы, `tools/`, `repositories/`),
`vm_menu/CHECKSUMS.sha256` (бүкіл мәзір: `menu.sh`, `bash_scripts/`, `ansible/` плейбуктары
мен рөлдері, шаблондар мен конфигтер) және `vendor/CHECKSUMS.sha256` (кірістірілген пакеттер
мен файлдар).

Тексерулер автоматты түрде орындалады: орнату кезінде (`sha256sum -c` барлық манифест бойынша,
сәйкессіздік орнатуды тоқтатады), мәзірді жаңарту кезінде (жүктелген мәзір жұмыс көшірмесін
ауыстырмас бұрын тексеріледі), кірістірілген nginx `.deb` орнату алдында және `vendor_get`
ішінде кез келген кірістірілген файлды қолданар алдында. Манифесттерді қайта есептеу —
`tools/checksums.sh --update`, тексеру — `tools/checksums.sh --check`.

# **Қолдану**
Мәзір **`/root/vm_menu`** каталогына орнатылады және **символдық сілтеме** жасалады:
- `/root/menu.sh` → `/root/vm_menu/menu.sh`

Мәзірді келесі пәрмендер арқылы іске қосуға болады:
```bash
./menu.sh   # Егер /root ішінде болсаңыз
/root/menu.sh   # Басқа каталогтан іске қосу үшін
```
Сондай-ақ, мәзір жолы **автоматты түрде `.profile`-ге қосылады**, сондықтан **SSH байланысы кезінде бірден іске қосылады**.

# **Баптаулар**
Мәзір икемді және оңай баптауға болады.  
Барлық параметрлерді келесі файлда өзгертуге болады:
```bash
/root/vm_menu/bash_scripts/config.sh
```
Бастапқы күйінде барлық параметрлер оңтайлы орнатылған, бірақ қажет болса, ортаны қажеттіліктеріңізге қарай бейімдей аласыз.

### Интерфейс тілі

Мәзір екі тілді: орыс және ағылшын. Тіл жүйе локаліне қарай автоматты түрде таңдалады:
`ru_RU.UTF-8` (немесе кез келген `ru_*`) — орыс тілі; кез келген басқа, соның ішінде `kk_KZ.UTF-8`
және `C.UTF-8` — ағылшын тілі.

Мәжбүрлеп таңдау — ортаның айнымалысы немесе `config.sh` ішіндегі `BS_MENU_LANG` параметрі:

```bash
BS_MENU_LANG=en /root/menu.sh   # орыс локальді серверде ағылшын тілі
BS_MENU_LANG=ru /root/menu.sh   # ағылшын локальді серверде орыс тілі
```

Интерфейстің барлық жолдары бір файлда сақталады — `/root/vm_menu/bash_scripts/i18n.sh`
(`MSG_RU` және `MSG_EN` сөздіктері).

# Скрипты установки окружения Bitrix (Debian 12 / Debian 13)

Скрипты воспроизводят официальное руководство 1С-Битрикс «Настройка окружения для Debian 13»
(пакеты, Nginx, PHP, Apache, MySQL/MariaDB, PostgreSQL, Redis, push-server) и дополнены
автоматизацией под стандартную схему Ansible (`playbooks/` + `roles/`).

В данном репозитории собраны скрипты для установки окружения Bitrix на **Debian 12** и **Debian 13**.  
Расширенный скрипт **`custom_bitrix_setup.sh`** добавляет **меню, аналогичное окружению для CentOS**, и включает автоматическую установку **MySQL 8.4 LTS** из официального репозитория Oracle (на Debian 12 — MySQL 8.0).

## Скрипт установки

- **`custom_bitrix_setup.sh`** — единственный скрипт установки окружения; его вызывает
  `install_full_environment.sh`. Создаёт `/root/run.sh` и выполняет его. Особенности:
  - **Меню, аналогичное окружению для CentOS**, что упрощает первичную настройку сервера.
  - **Автоматическая установка MySQL 8.4 LTS** из официального репозитория Oracle
    (на Debian 12 — MySQL 8.0).
  - **Альтернатива: Percona Server for MySQL 8.4 LTS** — выбирается переменной
    `DB_ENGINE=percona` (репозитории `ps-84-lts` и `telemetry`, телеметрия отключается).
  - Пресеты `my.cnf` под объём RAM (2g…64g) с автоматическим откатом, если MySQL
    не поднялся.
  - Воспроизводит официальное руководство
    [«Настройка окружения для Debian 13»](https://dev.1c-bitrix.ru/learning/course/index.php?COURSE_ID=32)
    и берёт внешние артефакты (push-server, конфиги PHP, скрипты установки Bitrix,
    ключи репозиториев) из локального каталога `vendor/` проекта с проверкой SHA256.

Скрипты для CentOS-ветки (`bitrix_gt.sh`, `bitrix24_gt.sh`, `bitrix_setup_vanilla.sh`)
удалены: они не использовались установщиком и скачивали архив `bitrixstable.tgz`
из стороннего репозитория.

## Альтернативные решения для развёртывания Bitrix

Если вам требуется другое окружение, вы можете также обратить внимание на:
- [ISPConfig сервер](https://github.com/Wladimir-N/ispconfig)
- [Bitrix Docker сервер](https://gitlab.com/bitrix-docker/server)

## Список пакетов и их назначение

Ниже перечислены пакеты, которые устанавливаются скриптами развёртывания окружения на Debian — **`install_full_environment.sh`** и **`custom_bitrix_setup.sh`**.

### 1. Ansible
**Назначение:** используется для финальной конфигурации окружения (запуск Ansible playbooks).

### 2. Apache2
**Назначение:** классический веб-сервер. Чаще всего Bitrix запускается на Apache, иногда совместно с Nginx.

### 3. apt-transport-https
**Назначение:** позволяет утилите `apt` скачивать пакеты по HTTPS.

### 4. build-essential
**Назначение:** базовый набор инструментов для компиляции (gcc, make и т. д.). Может понадобиться для сборки PHP-расширений или других библиотек.

### 5. ca-certificates
**Назначение:** набор корневых сертификатов (CA), необходим для корректной проверки SSL-сертификатов (https-запросы).

### 6. catdoc
**Назначение:** утилиты для конвертации документов Microsoft Word (.doc) в текст (бывает полезно при поисковой индексации в Bitrix).

### 7. cron
**Назначение:** планировщик заданий для системных скриптов и cron-агентов 1С-Битрикс.

### 8. curl / wget
**Назначение:** утилиты для скачивания файлов из интернета (репозитории, скрипты и т. д.).

### 9. debconf-utils
**Назначение:** позволяет автоматически «отвечать» на вопросы debconf (автоматизация установки пакетов в неинтерактивном режиме).

### 10. exim4 / exim4-config
**Назначение:** почтовый сервер (MTA). Используется для отправки системных уведомлений, писем с сайта и т. д.

### 11. git
**Назначение:** система контроля версий, используется для клонирования репозиториев (например, меню `vm_menu`).

### 12. gnupg2
**Назначение:** инструменты работы с GPG-ключами (подпись пакетов, добавление ключей репозиториев и пр.).

### 13. imagemagick
**Назначение:** набор утилит для обработки изображений (конвертация, сжатие). Может использоваться вместе с PHP Imagick.

### 14. libnginx-mod-http-brotli-filter / libnginx-mod-http-brotli-static
**Назначение:** модули Brotli для Nginx, обеспечивают дополнительное сжатие статики.

### 15. libreoffice-nogui
**Назначение:** офисный пакет без графической оболочки (headless-конвертация документов в PDF и другие форматы для сервера конвертации файлов).

### 16. locales / locales-all
**Назначение:** пакеты локализации (генерация нужной локали, например `ru_RU.UTF-8`) для корректной работы с мультиязычными данными.

### 17. lsb-release
**Назначение:** утилита, позволяющая получить информацию о дистрибутиве (например, `lsb_release -sc`), используется для добавления репозиториев.

### 18. make
**Назначение:** часть базового комплекта для сборки (обычно идёт вместе с build-essential).

### 19. mysql-server (MySQL 8.4 LTS на Debian 13, 8.0 на Debian 12)
**Назначение:** основная СУБД для хранения данных Bitrix. Ставится из официального репозитория Oracle. Заменяет MariaDB.

### 20. nftables
**Назначение:** современная подсистема файрвола в Linux (замена iptables). Настраивается для фильтрации и открытия нужных портов.

### 21. nodejs / npm
**Назначение:** нужны для установки и запуска push-сервера (push-server для веб-сокетов, уведомлений Bitrix24).

### 22. perl
**Назначение:** язык Perl, используется во многих системных скриптах и пакетах.

### 23. PHP-пакеты (для PHP 8.3):
**php8.3 libapache2-mod-php8.3 php8.3-cli php8.3-common php8.3-gd php8.3-ldap php8.3-mbstring php8.3-mysql php8.3-opcache php8.3-zip php8.3-pspell php8.3-xml php8.3-apcu php8.3-curl php8.3-redis php8.3-igbinary php8.3-mcrypt php8.3-memcache php8.3-dev php8.3-maxminddb php8.3-imagick php8.3-http**  
**Назначение:**  
- *php8.3*: основной интерпретатор PHP 8.3  
- *php8.3-cli / php8.3-common*: базовый набор для запуска PHP-скриптов  
- *php8.3-gd / php8.3-imagick*: обработка изображений  
- *php8.3-ldap*: работа с LDAP (если нужно авторизовывать через LDAP)  
- *php8.3-mbstring*: корректная работа с многобайтными строками (обязательно для Битрикс)  
- *php8.3-mysql*: драйвер для MySQL (mysqli, PDO)  
- *php8.3-opcache*: кеш байткода PHP (ускорение)  
- *php8.3-zip*: работа с zip-архивами  
- *php8.3-pspell*: проверка орфографии  
- *php8.3-xml*: XML-функциональность  
- *php8.3-apcu*: кеш объектов/данных в PHP  
- *php8.3-curl*: расширение cURL, HTTP-запросы из PHP  
- *php8.3-redis / php8.3-igbinary*: клиент Redis для PHP и быстрый сериализатор (нужны Bitrix и push-server)  
- *php8.3-maxminddb*: определение геолокации по IP (MaxMind)  
- *php8.3-mcrypt / php8.3-memcache / php8.3-http / php8.3-dev*: дополнительные модули, необходимые для некоторых скриптов и сервисов

> **Про метапакеты PHP — важно.** На `deb.sury.org` пакеты `php-pear`, `php-redis`, `php-igbinary` являются **метапакетами**: `php-pear` требует `php-xml` и подтягивает **PHP 7.4**, а `php-redis`/`php-igbinary` — самую новую ветку (**8.5**). В результате в системе оказываются три версии PHP, а `/usr/bin/php` переключается на чужую ветку. Расширение `php-geoip` для PHP 8 не собирается вовсе (последний билд — 7.4). Поэтому используются **только версионные пакеты** (`php8.3-redis`, `php8.3-igbinary`).

### 24. poppler-utils
**Назначение:** утилиты для работы с PDF (напр. `pdftotext`), полезно для индексирования документов.

### 25. pwgen
**Назначение:** утилита для генерации сильных случайных паролей.

### 26. redis
**Назначение:** in-memory хранилище Redis, используется для кеширования и сообщений (PUB/SUB) в Bitrix, а также совместно с push-сервером.

### 27. rsync
**Назначение:** синхронизация и копирование файлов и директорий (используется для копирования конфигов).

### 28. software-properties-common (не используется на Debian 13)
**Назначение:** пакет отсутствует в Debian 13; репозитории подключаются записью в `/etc/apt/sources.list.d/` без `add-apt-repository`.

### 29. ssl-cert
**Назначение:** инструменты для генерации самоподписанных сертификатов и работы с SSL.

### 30. unoconv (не используется на Debian 13)
**Назначение:** в Debian 13 пакет `unoconv` удалён из репозитория. Сервер конвертации файлов использует LibreOffice напрямую (`libreoffice-nogui`).

### 31. unzip
**Назначение:** распаковка zip-архивов (для установки Bitrix-конфигов, пакетов и пр.).

# **ინფორმაცია**
მენიუ Bitrix-ის გარემოს სამართავად, ადაპტირებული **Debian 12 / Debian 13**-ისთვის. მთავარი სამიზნე — Debian 13 (trixie): პროექტი ცვლის CentOS 9 გარემოს თანამედროვე Debian მანქანებზე.  
დაფუძნებულია [(YogSottot) bitrix-gt](https://github.com/YogSottot/bitrix-gt) პროექტზე და ოპტიმიზირებულია **თანამედროვე Debian 12–13 და Bitrix**-ისათვის.

# **გარემოს შესაძლებლობები**
- ყველა საჭირო კომპონენტის სრული ავტომატური ინსტალაცია:  
  **Ansible, PHP 8.3 (ნაგულისხმევი), MySQL 8.4 LTS, Nginx, Apache, Redis, Push & Pull სერვერი.**
- **მონაცემთა ბაზის ძრავის არჩევა: Oracle MySQL 8.4 LTS ან Percona Server 8.4 LTS** (`DB_ENGINE` ცვლადი).
- **კომპოზიტის მხარდაჭერა**.
- სტატიკური ფაილების **Brotli-თ გადაცემა**.
- შესაძლებლობა **Nginx-ის პერსონალური კონფიგურაციების გამოყენება** სტანდარტულის ცვლილების გარეშე.
- **Sphinx-ის სრული ტექსტური ძიების მხარდაჭერა**.
- **დოკუმენტების კონვერტაციის სერვერის (`LibreOffice`, `ImageMagick`) ინსტალაციის და მორგების** შესაძლებლობა.
- **Netdata-ის ინსტალაციის და მონიტორინგის** შესაძლებლობა.

# **მენიუს შესაძლებლობები**
- საიტების სიის ნახვა.
- საიტების შექმნა და წაშლა **ბირთვისა და სიმბოლური ბმულის რეჟიმში**.
- საიტის ბირთვულ რეჟიმში შექმნისას **აგენტების ავტომატური გადატანა CRON-ზე**.
- **Let’s Encrypt SSL სერტიფიკატების გამოშვება**.
- **HTTP → HTTPS გადამისამართების მართვა**.
- **PHP-ის ვერსიების შეცვლა**.
- **SMTP-ის კონფიგურაცია** (გლობალურად და თითოეული საიტისთვის ინდივიდუალურად).
- **სერვერის განახლება, გადატვირთვა და გამორთვა** მენიუს მეშვეობით.
- მენიუს ახალი ვერსიის გამოსვლის შესახებ შეტყობინება.
- **მენიუს განახლება ერთი ბრძანებით**:
  ```bash
  update_menu
  ```
- **ინტერფეისის ორი ენა — რუსული და ინგლისური** — ავტომატურად შეირჩევა სისტემის ლოკალის მიხედვით (`ru_*` → რუსული, ნებისმიერი სხვა → ინგლისური); შეიძლება იძულებით დაყენება `BS_MENU_LANG` ცვლადით.
- **PostgreSQL Bitrix-ისთვის** — ინსტალაცია და წაშლა დამატებების მენიუდან, `postgresql.conf`-ის პრესეტებით RAM-ის ზომის მიხედვით.

## მონაცემთა ბაზის ძრავის არჩევა: MySQL ან Percona Server
ინსტალატორი იძლევა **Oracle MySQL 8.4 LTS**-ის ან **Percona Server for MySQL 8.4 LTS**-ის არჩევის საშუალებას. ორივე იყენებს ერთსა და იმავე სერვისს (`mysql.service`), კონფიგურაციის საქაღალდეს (`/etc/mysql/conf.d/99-bitrix.cnf`) და ავთენტიფიკაციის რეჟიმს (`mysql_native_password`), ამიტომ Bitrix ორივე შემთხვევაში ერთნაირად მუშაობს.

```bash
# ინტერაქტიული არჩევანი (ნაგულისხმევად MySQL)
bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)

# Percona Server 8.4 LTS, კითხვების გარეშე
DB_ENGINE=percona bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)

# Oracle MySQL 8.4 LTS, კითხვების გარეშე
DB_ENGINE=mysql bash <(curl -sL https://raw.githubusercontent.com/Bx-Project-Hub/DebianBitrixVM/master/install_full_environment.sh)
```

**შემოწმებულია სუფთა Debian 13 (trixie), amd64-ზე:** PHP 8.3.36 (სისტემაში PHP-ის ერთადერთი განშტოება), MySQL/Percona 8.4.11, Nginx 1.26.3, Apache 2.4.69, Node.js 20.19.2, push-server 0.4.0; ყველა სერვისი აქტიურია; საიტის შექმნა `full` და `link` რეჟიმებში მუშაობს.

## PostgreSQL Bitrix პორტალისთვის

ინსტალირდება მენიუდან: პუნქტი `8` → «დამატებითი კომპონენტები» → `4`. MySQL აგრძელებს მუშაობას — მონაცემთა ბაზა პორტალის ინსტალაციისას აირჩევა.

| RAM, გბ | ბუფერის პული | დამგეგმავის ქეში | work_mem | მომსახურება |
|---|---|---|---|---|
| <3 | 512MB | 1536MB | 4MB | 128MB |
| 3&#8209;6 | 1GB | 3GB | 6MB | 256MB |
| 6&#8209;12 | 2GB | 6GB | 8MB | 512MB |
| 12&#8209;24 | 4GB | 12GB | 12MB | 1GB |
| 24&#8209;48 | 8GB | 24GB | 16MB | 1GB |
| ≥48 | 16GB | 48GB | 24MB | 2GB |

| RAM, გბ | კავშირები | WAL ბუფერი | Temp ბუფერი |
|---|---|---|---|
| <3 | 40 | 16MB | 8MB |
| 3&#8209;6 | 60 | 16MB | 8MB |
| 6&#8209;12 | 80 | 16MB | 16MB |
| 12&#8209;24 | 85 | 16MB | 24MB |
| 24&#8209;48 | 200 | 16MB | 32MB |
| ≥48 | 300 | 16MB | 48MB |

პარამეტრების სრული სახელები: ბუფერის პული — `shared_buffers`, დამგეგმავის ქეში — `effective_cache_size`, მომსახურება — `maintenance_work_mem`, კავშირები — `max_connections`, WAL ბუფერი — `wal_buffers`, temp ბუფერი — `temp_buffers`.

ავტომატურად იქმნება: ბაზა `bitrix` (`LC_CTYPE='C.UTF-8' TEMPLATE template0`), მომხმარებელი `bitrix`, `GRANT CREATE` სქემაზე `public`, გაფართოება `pgcrypto`, პაროლური ავთენტიფიკაცია `pg_hba.conf`-ში.

პრესეტი შეირჩევა პირველი შესაბამისი ზღვრის მიხედვით; იძულებით — `BS_POSTGRES_PRESET` `config.sh`-ში.

# **გამოყენება**
მენიუ **`/root/vm_menu`** დირექტორიაში ინიშნება და **სიმბოლური ბმული** იქმნება:
- `/root/menu.sh` → `/root/vm_menu/menu.sh`

მენიუს გაშვება შესაძლებელია შემდეგი ბრძანებებით:
```bash
./menu.sh   # თუ იმყოფებით /root დირექტორიაში
/root/menu.sh   # ნებისმიერი სხვა დირექტორიიდან გაშვებისას
```
ასევე, მენიუს ბილიკი **ავტომატურად ემატება `.profile` ფაილში**, ამიტომ **SSH-ით შეერთებისას ავტომატურად ჩაირთვება**.

# **კონფიგურაცია**
მენიუს მოქნილი კონფიგურაციის შესაძლებლობა აქვს.  
ყველა პარამეტრის შეცვლა შესაძლებელია შემდეგ ფაილში:
```bash
/root/vm_menu/bash_scripts/config.sh
```
ნაგულისხმევი პარამეტრები ოპტიმალურადაა შერჩეული, თუმცა საჭიროების შემთხვევაში შეგიძლიათ მოირგოთ თქვენი მოთხოვნებისთვის.

### ინტერფეისის ენა

მენიუ ორენოვანია: რუსული და ინგლისური. ენა ავტომატურად შეირჩევა სისტემის ლოკალის მიხედვით:
`ru_RU.UTF-8` (ან ნებისმიერი `ru_*`) — რუსული; ნებისმიერი სხვა, მათ შორის `ka_GE.UTF-8`
და `C.UTF-8` — ინგლისური.

იძულებითი არჩევანი — გარემოს ცვლადი ან `config.sh`-ში არსებული `BS_MENU_LANG` პარამეტრი:

```bash
BS_MENU_LANG=en /root/menu.sh   # ინგლისური რუსული ლოკალის სერვერზე
BS_MENU_LANG=ru /root/menu.sh   # რუსული ინგლისური ლოკალის სერვერზე
```

ინტერფეისის ყველა სტრიქონი ინახება ერთ ფაილში — `/root/vm_menu/bash_scripts/i18n.sh`
(ლექსიკონები `MSG_RU` და `MSG_EN`).
